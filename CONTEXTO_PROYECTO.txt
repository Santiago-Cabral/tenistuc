1) QUÉ ES
--------------------------------------------------------------------------------
App de tenis amateur (Tucumán, Argentina): ranking ELO, rivales, desafíos,
chats 1:1, torneos con inscripción PAGA (MercadoPago), notificaciones push.

Stack:
- Frontend: React Native + Expo (SDK recent) + Expo Router + Zustand
- Backend: Supabase (Auth + Postgres + Realtime + Edge Functions)
- Pagos: MercadoPago Checkout Pro marketplace (sellers = organizadores)
- Notificaciones: Supabase DB + Expo Push (client y edge functions)
- Fuentes: Lexend (headlines) + Plus Jakarta Sans (body)
- Tema: theme "The Kinetic Court" en src/theme/index.ts

3) CONVENCIONES CRÍTICAS (¡NO ROMPER!)
--------------------------------------------------------------------------------
- TypeScript estricto. Verificar SIEMPRE con:  npx tsc --noEmit
- NO usar el comentario que se agrega a los archivos. No usar Deno en edge
  functions: patrón = export default async function handler(req: Request),
  env con process.env, helper json(body, status). Copiar de notify/index.ts.
- Mensajes de UI en español argentino; identificadores de código en inglés.
- ALERTAS/DIALOGOS: usar SIEMPRE showAlert(...) de src/services/appAlert.tsx
  (con marca). Prohibido volver a Alert.alert de react-native.
- UI: componentes de src/components/ui, tema de src/theme (nada hardcodeado).
- Supabase client: las queries desde el cliente se hacen con supabase-js.
  Las operaciones que necesitan service role (enviar push, MP) se hacen en
  edge functions con SUPABASE_SERVICE_ROLE_KEY.
- Pagos: Checkout Pro marketplace. Cada organizador vincula su cuenta con
  OAuth (access_token en organizer_mp_accounts). La comisión se manda como
  marketplace_fee (porcentaje = env MERCADOPAGO_APP_FEE_PCT). Código
  marketplace = env MERCADOPAGO_MARKETPLACE. Risk: mp_status in registration.
